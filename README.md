## 🚀 Featured Projects

### ⭐ [PR-AI Auditor](https://pr-ai.onrender.com/auditor)
An AI code-review platform that analyzes GitHub and GitLab pull requests, branches, and commits for correctness, security, scalability, and regression risk. It includes inline code comments, Mermaid impact diagrams, AI chat over diff context, and Whisper voice input.

**Stack:** Laravel · OpenAI API · GitHub API · GitLab API · Monaco Editor · Diff2HTML · Mermaid.js · Whisper

### 🩺 Tarok Nurses Management System
A healthcare CRUD platform for digitizing records and administrative workflows for the Tarok Nurses group.

**Stack:** Native PHP · MySQL · phpMyAdmin · Brevo

🔗 [View the live system](https://bolitupac.infinityfree.io/TNF-website/)

### 👗 Wardrobe Planner AI
A mobile AI concept using computer vision and large language models to analyze personal style and plan daily outfits.

**Stack:** React Native · Computer Vision · LLMs

### 🏆 [One Chance, Mossy Escape](https://github.com/Bolitupac/One-Chance--Mossy-Escape)
A Godot 2D platformer that won the Clash of Devs 2.0 Game Jam Nigeria through immersive storytelling, responsive movement, and tight collision design.
